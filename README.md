# SRT_DUMP

## Описание

Программа нужна для снятия дампов SRT источников без шифрования.
Она имеет один обязательный парметр "-u" через который передается ссылка.

Внутри себя она парсит ссылку и проверят её корректность:
* Протокол - srt://;
* ip адрес сервера - проверяет каждый октет;
* Порт - проверяет не выходит ли порт из общего допустимого диапозона сетевых портов;

Также примнимает такие флаги:
* -c - число пакетов которые примет утилита (по умолчанию 5);
* -f - файл в который будет записана полезная нагрузка (по умолчанию /dev/null);

## Build

Перед тем как собрать у вас должна быть установлена статическая библиотека srt.
Можно компиляцию переделать и под динамическую сбороку.

Так я собираю данный проект на своей машине:

```bash
user@pc:~/SRT_DUMP $ mkdir build && cd build
user@pc:~/SRT_DUMP/build $ g++ ../source/main.cpp ../source/client_srt.cpp -static-libstdc++ -static-libgcc \
-I ../include -std=c++17 -lsrt -lssl -lcrypto \
-lpthread -ldl -Wall -g -O2 -o srt_dump
```

Скоро выйдет Dockerfile для сборки под ldd версии 2.31.
Под эту версию и задумывался данный проект.
Но сборка указанна выше должна пройти и на 2.35 версии.

## Как локально провести тест?

Для локальной проверки вы можете запустить ffmpeg для раздачи потока по SRT протоколу:

```bash
ffmpeg -re -i <mp4 file> -c copy -f mpegts "srt://127.0.0.1:2020?mode=listener"
```

```bash
./srt_dump -u srt://127.0.0.1:2020 -c 20 -f video.ts # примет 20 пакетов и сохранит в video.ts
./srt_dump -u srt://127.0.0.1:2020 -c 20 # примет 20 пакетов и сохранит в /dev/null
./srt_dump -u srt://127.0.0.1:2020 # примет 5 пакетов и сохранит в /dev/null
```

Пример того как это выглядит в живую:

```bash
ffmpeg -re -i rio.mp4 -c copy -f mpegts "srt://192.168.0.43:2020?mode=listener"
```

```bash
./srt_dump -u srt://192.168.0.43:2020 -c 20
Подключение к 192.168.0.43:2020...
Успешно подключено! Принимаем поток...
Файл сохранен как /dev/null. Всего байт: 13160
```
